Assignment 1
Topic
Contact Manager using ADT Sorted List

Description
This assignment is about developing a Contact Manager application in C++ using Abstract Data Types (ADT) and a sorted list.

The program stores contact details in sorted order based on name.

Features
Add a new contact (kept sorted by name)
Search a contact by name
Delete a contact
Display all contacts in ascending order
Data Structure Used
Sorted List (Array-based ADT)
Validation
Name: alphabets only
Phone: digits only (fixed length)
Address: cannot be empty
Language
C++
