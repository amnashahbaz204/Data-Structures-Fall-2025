Topic: Flight Reservation Directory using Binary Search Tree (BST)

Description: This assignment is about implementing a Flight Reservation Directory using a Binary Search Tree in C++. Each node in the BST represents a flight record stored using Flight ID as the key. The system helps manage flight information and perform different operations like searching, sorting, and grouping.

Flight Information Stored:

Flight ID (BST Key)
Destination
Departure Time
Flight Duration
Flight Status (Departed, Landed, Delayed)

Features:

Insert a new flight record (BST insertion)
Delete a flight record (BST deletion)
Search flight by Flight ID
Display all flights in sorted order (Inorder traversal)
Display flights grouped by destination
Display flights grouped by status
Calculate ETA (Departure Time + Duration)
Show flight punctuality status (On-Time / Early / Delayed)
Surprise feature (custom enhancement)

Data Structure Used:

Binary Search Tree (BST)

Implementation Notes:

Flight ID is used as the key for BST ordering
Inorder traversal is used for sorted output
Menu-driven interface is used for user interaction
Language: C++
