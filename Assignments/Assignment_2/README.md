Assignment 2
Topic
Infix to Postfix and Prefix Conversion using Stack

Description

This assignment is about converting an infix expression into postfix and prefix notations using stack data structure.

Postfix and prefix notations are used because they are easier to evaluate and do not require parentheses.

Features

Accept an infix expression as input
Convert infix to postfix
Convert infix to prefix
Use stack (array-based ADT implementation)
Rules Implemented
Operator precedence (^, *, /, +, -)
Parentheses handling
Proper conversion algorithms
Example
Input: (a+b)*c^d-e/f

Postfix: ab+cd^*ef/- Prefix: *+ab^cd/ef

Data Structure Used
Stack (Array-based ADT)
Language
C++
